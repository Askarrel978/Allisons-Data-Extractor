Allison's Data Extractor - Revision 1.3.0

Multiple Template B tables
- Every shipment table in an image is now found and read on its own: any number of tables, stacked or side by side, of different sizes and positions, in dark or light theme, and inside a larger email screenshot.
- Each table becomes its own row, even when OCR cannot read its "Plant Species" heading.
- A row whose label cannot be read is placed by Template B's fixed row order, but only when the value fits that field; the record is flagged for review.
- Sales order, lot code, date and customer are read several times at different magnifications and the majority is used. When the readings disagree, the record says so and shows both values.
- Lot codes that differ only in characters OCR can confuse (I/1, O/0, S/5, B/8, Z/2) are flagged, both within one file and against lot codes already in the selected workbook.
- Multi-pack plant counts such as 1520 heads (12 heads x 60 cases / 16 heads x 50 cases) are checked correctly, and Pack Style is checked against the heads per case.
- Fixed the recurring OCR misread of "12x1ct clam" as "12x1ict dam".
- Template B PDFs, such as an Outlook email printed to PDF, now produce one row per shipment table instead of a single mixed-up row. A table cut off at the end of the printout is flagged as incomplete.
- Scanned Template B PDFs, and PDFs whose shipment table is a pasted picture, are read with the same table engine.
- Reprocess on a multi-table image now refreshes every row from that file without creating duplicates.
- Transparent PNGs, multi-page TIFFs, rotated phone photos and high-resolution screenshots are handled.

Reliability and speed
- Extraction and Reprocess now run in the background without freezing or destabilizing the window.
- Buttons that could interfere with a running extraction are disabled until it finishes, so it cannot be started twice.
- Settings are cached and only re-read when they change, which makes extraction noticeably faster.
- Template B table detection is much faster on large images.
- Fixed a table edit being recorded twice in History, and a crash when editing a cell scrolled out of view.

Scanned PDF support
- PDFs without selectable text (scanned or photographed pages) are now read with the bundled Tesseract OCR instead of being rejected.
- Scanned-PDF rows receive an OCR warning and a configurable confidence reduction, so they always require review.
- Added OCR scanned PDFs and Scanned PDF confidence penalty to Settings > OCR.

Excel export
- Values are written under the matching column headings, so workbooks with a different column order or extra columns stay aligned.
- Data is written to the sheet that holds the Date / Sales Order Number headings, even if another sheet is active.
- New rows follow directly after the last filled row, without gaps left by formatted empty rows.
- Your own column widths are no longer overwritten on every export.
- Workbooks are saved through a temporary copy and swapped into place, so an interrupted export cannot corrupt the original file.
- The program checks that the workbook is not open in Excel before creating a backup or writing.
- After a successful export you can clear the exported rows from the table to avoid exporting them twice.

- Added a Settings search box that jumps to the most relevant settings category.
- Added Production Safety Mode for high-accuracy production use.
- Production Safety Mode blocks export when required fields are missing.
- Production Safety Mode requires manual approval for records below the configured Verified confidence threshold.
- Added an optional warning before exporting records that still contain validation warnings.
- Added configurable Excel export confirmation, automatic backups, duplicate checking, and optional opening of the output folder after export.
- Added History & Audit preferences for manual edits, approvals, and export events.
- Added History CSV export and Clear Processing History controls in Settings.
- Added a read-only Templates overview showing configured templates, source type, markers, lot-code requirement, and status.

- Added a Diagnostics page with checks for application-data write access, settings, Excel engine, history database, Tesseract OCR, and updater availability.
- Added Create Diagnostic Package, which creates a sanitized ZIP without shipment source files, extracted shipment records, processing history, or administrator credentials.
- Added administrator auto-lock timeout configuration from 1 to 240 minutes.
- Added an About page in Settings with application revision, developer information, Help, application-data folder access, and a Changelog button.
- Existing configuration import/export, backups, administrator passcode protection, and USB/local update installation remain available under Backend / Administrator.

Revision 1.2.0

Major additions
- Updated the application branding to Allison's Data Extractor across the GUI, executable, build system, settings, updater, and release packages.
- Added automatic migration of existing local settings/history from earlier development builds into the Allison's Data Extractor application data folder.
- Added a Settings button with a gear icon on the main window.
- Improved the Changelog window with Segoe UI typography, styled release headings, readable bullets, and better spacing.
- Added General, Data Formatting, OCR, and Backend / Administrator settings sections.
- Added administrator passcode protection using a salted PBKDF2 password hash; the passcode itself is never stored.
- Added first-run administrator passcode creation and passcode change support.
- Administrator mode automatically locks after 15 minutes.
- Added configurable template markers, lot-code requirements, Sales Order validation regex, and Template B record-start terms.
- Added advanced JSON configuration editing for administrator use, including PDF label/regex rules and Template B OCR/grid terms.
- Added Test Configuration with Sample so administrators can verify document-reading changes before deployment.
- Added configuration import/export and automatic configuration backups.
- Added configurable OCR confidence penalty and confidence thresholds.
- Added Tesseract path override and a Tesseract test button.
- Added Pack Style normalization for consistent human-readable formatting.
- Compact pack styles such as 12x1ctClam, 12 X 1 CT clam, and 12x1ct clam normalize to 12x1ct Clam.
- Multi-pack styles use a consistent separator and Template C multiline packaging is cleaned into readable output.
- Pack Style aliases can be managed from Settings without rebuilding the program.
- Added support for remembering the last selected Excel output workbook.
- Added USB/local software update support through the administrator settings page.
- Update packages are revision checked, SHA-256 verified, staged locally, installed after the main app exits, and the program restarts automatically.
- Added a standalone updater helper so the running application can safely replace its own EXE and support files.
- Added automatic pre-update installation backups in LOCALAPPDATA.
- Added an update-package builder to create future USB update ZIP files from a compiled release.
- Improved portable Tesseract detection to also search PyInstaller's _internal / _MEIPASS locations.
- Suppressed noisy pdfminer FontBBox warnings that do not affect successful extraction.

Important update note
- Revision 1.2.0 is the first revision containing the in-app updater. Install 1.2.0 manually once (copy the new portable folder). Future revisions can then be loaded from a USB update ZIP through Settings > Backend / Administrator.
